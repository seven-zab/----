# 小程序界面改进方向（2026-11-04）

背景：乡村需求与深圳技术大学服务协作。用户反馈页面欠美观，个人资料没有头像展示；本轮以清晰的任务入口、资料状态和阅读体验为重点，不增加业务模块。

配色：田野绿#216653（主操作）、校园蓝#416c91（校园/消息）、正文#233e36、次要文字#697c75、底色#f3f7f5、白色#ffffff；分隔线#dfe9e3。使用设备中文字体PingFang SC/Microsoft YaHei/system-ui，减少外部字体下载；页标题40rpx、正文28rpx、辅助24rpx，均继承大字版倍率。

布局：左对齐。首页用一块田野线条的品牌区承载“乡村所需，校园所长”，主入口为发布需求与需求广场；政策和AI为次级入口。分类横向滚动，有明确选中态。个人页用真实头像、昵称和身份作为头部，履约入口与身份/管理入口分组，减少整屏相同大按钮。资料页上方显示当前或本次选择的头像，区分本地已选择、上传检查中、可保存及失败，保存后重新鉴权获取短链。私聊页采用会话列表和独立通知入口。其余页面统一表单、标题、状态、空态和操作层级。

```text
首页                         个人资料
品牌 / 大字版                 头像预览 + 当前状态
乡村所需，校园所长             更换头像 / 恢复原头像
发布需求 | 查看政策            昵称输入
AI业务助手                    上传或保存结果
需求广场 / 已审核公开           保存资料
分类横滑 + 任务列表
```

复核：原设计把所有功能做成同色大按钮，缺少信息层级。本轮将多数导航改成带图形及说明的行，主操作才实色；不堆砌数据卡、假统计或随机图片，不展示不存在的需求。特色集中在首页的田野图形，业务页保持克制。图形采用代码原生CSS线条/矢量，不引入生成照片。禁止以放宽存储读写、绕过域名校验解决头像展示。

验收：真机上传错误保留安全类别，不输出照片路径/签名；有意义测试覆盖上传错误分类、选择后预览、失败禁止误保存、头像换人/过期短链竞态；通过类型和构建后使用开发工具截图检查首页、个人、资料、消息及大字版。实际手机上传和视觉效果继续由真机复测确认。
