# AI 对话界面与图片上传修复（2026-11-07 晚间）

用户反馈：希望 AI 助手采用聊天界面，展示双方头像和思考状态；选择图片后输入文字消失且图片未显示；AI 追问后无法继续输入。

## 改动

- 助手页改为消息气泡、AI 标识、本人头像、历史对话、快捷示例和底部输入区。排队、思考、上传及失败均有对应提示；收到最终回复后保留输入框。业务结果卡仅显示一次。图片成功登记后在输入区显示缩略图；需求表单在上传按钮旁显示上传状态和错误。
- 原助手页监听 `() => [user_id, grant_id]`，每次同账号资料刷新也会生成新数组并触发重置。微信从相册返回会触发 App onShow 和账号刷新，因此可能清除草稿，并因版本号改变丢弃刚完成的图片结果。现改为分别监听两个原始值：同账号同身份刷新不清除内容，真实切换账号或身份仍清除旧状态。
- 账号刷新发生临时网络错误时保留当前身份和草稿；服务端明确返回未登录、账号不存在或禁用时仍清除身份。登出期间迟到的刷新结果不恢复旧登录。业务请求仍由服务端重新核验身份与权限。
- 为聊天中本人头像增加紧凑尺寸，修复开发工具窄屏截图中头像边缘裁切。快捷示例保留在输入区“快捷示例”内，点击填入后须本人发送。
