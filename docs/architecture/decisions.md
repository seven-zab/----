## 2. 记录规则

- `confirmed`：用户明确答复，写明轮次与决定，不把推荐答案自动视为同意。
- `pending`：尚未确认，不允许执行AI将已有默认值当成最终业务规定。
- `fact_checking`：由代码/环境核查解决，不把可查事实转为用户问答。
- `superseded`：被后续明确决定替代，保留历史原因，所有关联契约同步更新。
- 问题使用稳定编号；回答支持“全部按推荐，Qx改为……”。同一轮只问不依赖该轮其他未知答案的问题。
- 每轮登记受影响的页面、集合、接口、状态与验收场景；发现冲突先消解再冻结，不保留互相矛盾的两套规则。
