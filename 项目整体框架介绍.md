# 云治乡智 - 项目整体架构介绍

## 一、项目概述

**云治乡智** 是一款服务乡村振兴的微信小程序，基于 **uni-app + Vue3 + 微信云开发** 构建。

### 项目定位

```
┌─────────────────────────────────────────────────────────────┐
│                     云治乡智                                  │
│                  乡村振兴综合服务平台                           │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   🧑‍🌾 农户发布需求    🏛️ 村委审核管理    🎓 学校接取任务      │
│                                                             │
│   💬 即时通讯     📋 角色切换     📜 政策服务     🤖 智能客服   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 五、核心模块详解

### 1. 用户角色系统（多角色管理）

**角色类型**：

| 角色 | 代码 | 权限 |
|------|------|------|
| 普通用户 | `general_user` | 基础浏览 |
| 农户 | `farmer` | 发布需求、聊天 |
| 村委 | `local_admin` | 发布需求、审核、聊天 |
| 学校师生 | `school_admin` | 接取任务、聊天 |

**角色切换机制**：

```
用户属性结构：
{
  _id: "user_123",
  role: "farmer",                    // 当前角色
  status: "active",                  // 账号状态
  available_roles: [                 // 拥有的角色列表
    { role_code: "farmer", role_name: "农户" },
    { role_code: "local_admin", role_name: "村委" }
  ],
  current_context: {                 // 当前角色上下文
    region_code: "441623"
  }
}

切换角色：
┌─────────────────────────────────────┐
│  用户点击角色切换                     │
│  ↓                                  │
│  检查目标角色是否在 available_roles  │
│  ↓                                  │
│  调用云函数 switchRole               │
│  ↓                                  │
│  更新 store.role                    │
│  ↓                                  │
│  切换页面显示                        │
└─────────────────────────────────────┘
```

**权限控制**：

```typescript
// stores/user.ts
const hasRole = (roles: string[]) => {
  return roles.includes(role.value);
};

const canPerformAction = (action: string) => {
  if (status.value !== 'active') return false;

  const permissionMap = {
    'publish_demand': ['farmer', 'local_admin'],
    'audit_demand': ['local_admin'],
    'claim_task': ['school_admin'],
    'chat': ['farmer', 'local_admin', 'school_admin'],
  };

  return permissionMap[action]?.includes(role.value) || false;
};
```

### 2. 需求模块

**需求类型**：

```
┌─────────────────────────────────────────────────────────────┐
│                      三大需求类型                             │
├─────────────────┬─────────────────┬─────────────────────────┤
│    企需通        │     农践帮       │      科研实践厅           │
│  (enterprise)   │  (agriculture)  │     (research)          │
├─────────────────┼─────────────────┼─────────────────────────┤
│ 生产技术        │ 采摘打包        │ 种植技术                  │
│ 人才引进        │ 销售(电商)      │ 机械技术                  │
│                 │                 │ 智能技术                  │
└─────────────────┴─────────────────┴─────────────────────────┘
```

**需求流程**：

```
发布 → 审核 → 发布成功 → 被接取 → 执行 → 完成
  ↓      ↓
  └──────┘（拒绝/通过）

状态机：
┌─────────┐    村委审核     ┌──────────┐   学校接取   ┌──────────┐
│ pending │ ──────────────→ │ approved │ ──────────→ │  claimed │
└─────────┘  (approve/reject)└──────────┘              └──────────┘
    ↑                          │
    └──────────────────────────┘
         (rejected → 重新发布)
```

## 十一、总结

**云治乡智** 是一个典型的 **多角色小程序** 系统，核心特点是：

1. **多角色管理** - 农户、村委、学校师生三种角色，支持随时切换
2. **权限控制** - 基于角色的细粒度权限控制
3. **业务闭环** - 发布→审核→接取→完成 完整流程
4. **即时通讯** - 实时聊天功能
5. **测试完善** - 87个测试用例，覆盖核心业务逻辑
